# Revised data sources

Price observations come from the Colombo/Pettah daily wholesale workbook. Each row is a crop-date observation with a target equal to the mean wholesale price in the following calendar week.

Yield observations come from valid district-crop-season-year production records matched to a district weather location and a pre-forecast three-month weather window.

The weekly Colombo/suburbs workbook remains a documented source for comparison and historical checks; it is not concatenated with daily observations as if it were the same measurement process.
